PSN SERVER — CONFIGURAÇÃO DO RENDER
====================================

Use estas configurações no serviço do Render.

1. Runtime
----------
Runtime: Node

2. Build Command
----------------
npm ci --omit=dev

IMPORTANTE:
- Não use "yarn".
- O projeto usa package-lock.json, então mantenha npm.
- Se o Render estiver com "yarn" salvo no Build Command, substitua pelo comando acima.

3. Start Command
----------------
npm start

O package.json já executa:
node server.js

4. Node.js
----------
Versão recomendada:
22.22.0

O projeto já possui .node-version para fixar essa versão.

Se existir no Render uma Environment Variable chamada:
NODE_VERSION

Faça UMA destas opções:
- remova NODE_VERSION e deixe o .node-version controlar a versão;
OU
- defina NODE_VERSION como:

22.22.0

Não deixe NODE_VERSION configurado como Node 24 se quiser seguir a versão fixada no projeto.

5. Environment Variables
------------------------
Mantenha normalmente todas as variáveis que o servidor já usa no Render, principalmente:

DATABASE_URL

E quaisquer outras que você já tenha configurado, por exemplo:
IGDB_CLIENT_ID
IGDB_CLIENT_SECRET
TWITCH_CLIENT_ID
TWITCH_CLIENT_SECRET

Não apague variáveis existentes do servidor apenas por causa desta atualização.

6. Depois de alterar
--------------------
No Render:

Manual Deploy
→ Clear build cache & deploy

Faça isso uma vez depois de trocar Yarn por npm e atualizar os arquivos.

7. Como o deploy deve aparecer
------------------------------
O log deve mostrar algo equivalente a:

Running build command 'npm ci --omit=dev'...

e NÃO:

Running build command 'yarn'...

Depois:

npm start
node server.js

8. Resumo
---------
Runtime: Node
Node: 22.22.0
Build Command: npm ci --omit=dev
Start Command: npm start
Package Manager: npm
Lockfile: package-lock.json

Depois das alterações:
Clear build cache & deploy
